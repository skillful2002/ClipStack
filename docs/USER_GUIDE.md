# ClipStack 使用说明

ClipStack 是一款**本地优先、隐私可控**的跨平台剪贴板历史管理工具。它会自动记录你在系统中复制过的文本、链接、代码、图片与文件，让你随时回溯、检索并一键重新粘贴。所有数据默认只保存在你本机，不上传任何第三方。

---

## 一、安装与启动

ClipStack 提供 macOS、Windows、Linux 的安装包，前往下方任一发布页面下载对应系统的安装文件即可：

- **Gitee 发布页（国内访问更快）**：<https://gitee.com/liuzhengguo/ClipStack/releases>
- **GitHub Releases**：<https://github.com/skillful2002/ClipStack/releases>

安装完成后启动应用，它会在系统托盘（菜单栏 / 通知区域）常驻一个图标，不会占用任务栏空间。第一次启动会请求「访问剪贴板」的系统权限，请允许，否则无法捕获复制内容。

---

## 二、主界面与基本操作

主界面分为三部分：**左侧导航**（搜索、分类、回收站 / 设置 / 帮助 / 关于）、**中间历史列表**、**右侧详情面板**。

- **自动记录**：你复制的任何内容（⌘C / Ctrl+C）都会自动出现在历史列表中，无需手动保存。
- **重新使用**：在列表选中某条，点击右侧「复制」或按 `Enter`，内容会写回系统剪贴板，随后直接粘贴即可。
- **置顶**：点击「置顶」（快捷键 `P`）把常用条目钉在列表顶部，不被新内容冲掉。
- **收藏**：点击「收藏」（快捷键 `F`）把条目加入收藏，方便长期保留。
- **删除**：点击「删除」（快捷键 `Delete` / `Backspace`）把条目移入回收站，可在回收站恢复。

> 提示：列表中的「来源应用」「大小」「时间」等元信息帮助你快速分辨内容出处。

---

## 三、分类筛选与搜索

左侧导航按内容类型分了 **全部 / 文本 / 链接 / 代码 / 图片 / 文件** 六类，点击即可只看对应类型（`⌘1`–`⌘6`）。列表上方的「时间」筛选支持 今天 / 昨天 / 本周。

顶部搜索框（快捷键 `⌘/`）可实时按关键词检索——匹配范围包括内容正文、来源应用与预览文本，快速定位历史里的某段内容。

## 五、设置

点击侧边栏「设置」（`⌘,`）打开设置页。设置分为**通用 / 安全 / 共享**三个标签，点击标签切换：

### 通用

- **外观**：主题支持浅色 / 深色 / 跟随系统；语言内置简体中文、繁体中文、English、日本語、Deutsch、Français，可手动指定或跟随系统。
- **存储**：设置历史记录上限（超出后最旧记录自动清理）、托盘菜单显示的最近条数。
- **留存过期**：设置保留天数，超期未置顶的历史与回收站内容会被自动清理（默认永久保留）。
- **保存的历史类型**：分别开关文本 / 图片 / 文件的捕获，关闭的类型不再被记录（已存在记录保留）。
- **开机自启**：登录后自动启动 ClipStack。

### 安全

- **忽略的应用**：被加入列表的应用（如密码管理器、终端）其复制内容不会被 ClipStack 捕获，保护敏感信息。
- **安全**：
  - **主密码 / 应用锁**：设置主密码后，手动锁定、窗口失焦或闲置超时需输入密码解锁；macOS 可开启 Touch ID / 登录密码解锁（需 Xcode Command Line Tools）。
  - **敏感内容掩码**：开启后，命中密码 / Token / 银行卡号的内容在预览中以 `••••••` 遮挡，原文仍加密且可正常复制。

### 共享

- **局域网共享（LAN 同步）**：在同一局域网内端到端加密互享剪贴板，无服务器、不上云。可配置共享组 / 共享密钥 / 端口、文件大小上限、共享类型过滤与手动对端；开启前需先设置共享组、共享密钥、端口三项参数。详见第九节。

## 六、回收站

删除的条目不会立刻消失，而是进入回收站，可在「回收站」中**恢复**或**彻底删除**；也可一键清空回收站。

---

## 七、托盘菜单

点击系统托盘图标弹出菜单，包含：

- **共享**：切换局域网共享开关，左侧圆点指示当前状态（亮色 = 已开启，暗色 = 已关闭）。开启共享前需先设置共享组、共享密钥与端口三项参数。
- **最近历史**：直接点击或按 `⌘1`–`⌘9` 即可把对应条目复制回剪贴板。
- **打开主界面**（`⌘⇧V`）
- **设置**（`⌘,`）
- **帮助**、**关于系统**、**退出**

即使在主窗口关闭的情况下，也能通过托盘菜单快速粘贴最近复制过的内容。

## 八、安全与隐私

ClipStack 把「本地优先、隐私可控」放在首位，数据安全由以下几层保障：

- **本地加密（始终开启）**：剪贴板正文与图片 / 文件二进制以 **AES-256-GCM** 在本地 SQLite 中加密存储，仅 `content_text` / `content_blob` 两列加密，其它字段（类型、来源、时间、哈希）保持明文以便检索。加密密钥存于 `~/.clipstack/dbkey.dat`（权限 600），与你的主密码相互独立——修改或清除主密码都不会影响已加密的数据。
- **应用锁**：在「设置 → 安全」中可设置主密码；手动锁定、窗口失焦或闲置超时后需输入密码解锁。macOS 上可开启 **Touch ID / 登录密码**解锁（需安装 Xcode Command Line Tools）。主密码仅用于解锁应用，不参与数据加解密。
- **敏感内容掩码**：开启「掩码敏感内容」后，命中密码 / Token / 银行卡号等规则的内容在列表与详情中以 `••••••` 遮挡预览；原文仍加密存储且可正常复制，开关即时生效。
- **留存过期**：在「设置 → 留存过期」中设置保留天数，超过后未置顶的历史与回收站内容会被自动清理，避免敏感数据无限累积。
- **保存类型过滤**：在「设置 → 保存的历史类型」中可分别开关文本 / 图片 / 文件的捕获，关闭的类型不再被记录（已存在记录保留）。

> 提示：锁定态下 ClipStack 仍会持续加密捕获剪贴板，复制内容不会因锁定而丢失；解锁只需密码或 Touch ID，安全与使用体验兼顾。

## 九、局域网共享（LAN 同步）

ClipStack v0.2.0 起已内置**局域网共享**：同一局域网（WiFi / 有线）内的多台设备可端到端加密互享剪贴板，无需服务器、不上云。

**开启前准备**：在「设置 → 局域网共享」中先设置三项参数，三者缺一不可，未设置时开启共享会被拦截并提示：

- **共享组**：逻辑分组标识（如 `home` / `office`），只有同组的设备才会互享。
- **共享密钥**：对称密钥源，私密；与共享组一起决定能否建立共享（指纹不含密钥原文，局域网广播不泄露密钥）。
- **端口**：本机监听端口（默认 `8787`）。

**使用要点**：

- 「设置 → 局域网共享」可配置全部参数：共享组、共享密钥、本机端口（默认 `21995`）、文件大小上限、共享类型过滤（文本 / 图片 / 文件）、手动对端与来源标识（设备名）。
- 每台设备可独立开关「是否启用局域网共享」（开关 `share_out`）。关闭后本机既不发送也不接收任何共享内容，已发布的内容无法远程撤回。
- 文件共享默认上限 100MB（可在设置中调整），超限文件不会离开本机；文件夹 / 目录包（如 macOS 的 `.rtfd` 包）也能完整传输。
- 跨 VLAN 或组播被禁的网络环境，可在「手动对端」中填写对方 `IP:端口` 兜底直连。
- 托盘菜单的「共享」项左侧圆点代表当前状态，点击即可一键切换。
- 收到的图片与文件可在历史列表的悬浮菜单选择「另存为」，保存到本机指定位置。
- 在线设备列表显示组内其他成员（显示设备名，不显示设备 ID）。

> 局域网共享的技术设计文档位于项目仓库的 `docs/clipstack-lan-sync-design.md`；跨公网 / NAT 穿透的中继同步（clipstack-relay）将在未来版本推出。

## 常见问题

**Q：复制了内容却没出现在历史里？**
A：请确认已授予剪贴板访问权限，且来源应用不在「忽略的应用」列表中；部分安全软件也可能拦截。

**Q：关闭主窗口后还在运行吗？**
A：是的， ClipStack 默认驻留托盘后台运行以持续捕获剪贴板；从托盘菜单「退出」才会彻底关闭。

**Q：数据存在哪里？**
A：所有记录保存在本机本地数据库（SQLite），不上传任何云端。数据库中的剪贴板正文与图片 / 文件二进制以 AES-256-GCM 加密存储（密钥在 `~/.clipstack/dbkey.dat`，权限 600），即使数据库文件被拷贝走也无法直接读取明文。
