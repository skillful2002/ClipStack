# ClipStack 使用说明（用户手册）

> 适用版本：**v0.2.3** · 应用标识：`tech.newxin-clipstack.app`
> 技术栈：Tauri 2 + React 18 + TypeScript + Vite + Rust（SQLite 持久化）

ClipStack 是一款**本地优先、隐私可控**的跨平台剪贴板历史管理工具。它会自动记录你在系统中复制过的文本、链接、代码、图片与文件，让你随时回溯、检索并一键重新粘贴。所有数据默认只保存在你本机，不上传任何第三方。它还支持**在局域网内进行剪贴板共享**：同一局域网内的多台设备可端到端加密互享剪贴板，并**可配置共享类型**（文本 / 图片 / 文件）按需开启或关闭。

## 一、安装与启动

### 1.1 下载安装包

ClipStack 当前为 **macOS** 与 **Windows** 提供官方安装包（Linux 处于规划中，暂未发布正式安装包）。前往下方任一发布页下载对应系统的安装文件：

- **Gitee 发布页（国内访问更快）**：<https://gitee.com/liuzhengguo/ClipStack/releases>
- **GitHub Releases**：<https://github.com/skillful2002/ClipStack/releases>

| 平台 | 安装包形态 | 状态 |
|---|---|---|
| macOS | `.dmg`（含「拖到 Applications」快捷方式）/ `.app` | ✅ 支持（最低 macOS 10.15 Catalina） |
| Windows | `.msi` | ✅ 支持 |
| Linux | 托盘应用 | 规划中（暂未发布安装包） |

### 1.2 首次启动

安装完成后启动应用，它会在系统托盘（菜单栏 / 通知区域）常驻一个图标，不会占用任务栏空间。

- **权限请求**：第一次启动会请求「访问剪贴板」的系统权限，**请务必允许**，否则无法捕获复制内容。
- **首启引导**：首次运行会自动打开设置页完成初始化；非首次启动仅驻留菜单栏 / 托盘（macOS 无前台窗口时不显示 Dock 图标）。
- **关闭 ≠ 退出**：关闭主窗口只是隐藏窗口，应用仍常驻托盘后台运行以持续捕获剪贴板；从托盘菜单「退出」才会彻底关闭。

### 1.3 自己从源码构建（进阶）

如果你想自行打包安装包，仓库根目录提供了构建脚本（需先安装 [开发环境](#附录开发环境要求)）：

```bash
# macOS：生成 .dmg（默认构建本机实际架构；可指定 x86_64 / universal）
bash build-macos-dmg.sh
bash build-macos-dmg.sh x86_64-apple-darwin      # 仅 Intel 包（产物名 ..._x64.dmg）
bash build-macos-dmg.sh universal-apple-darwin   # 通用二进制（..._universal.dmg）

# Windows：生成 .msi
build-msi.bat      # 在 Windows 上双击或命令行执行
bash build-msi.sh  # 在类 Unix 环境交叉/本地构建
```

> 说明：Tauri 自带的 create-dmg 在 CI / 无 GUI 环境下会因 AppleScript 权限问题失败；`build-macos-dmg.sh` 改用 `hdiutil` 直接生成 dmg，绕过该问题，产物仍为可正常安装的完整安装包。

## 二、主界面与基本操作

主界面分为三部分：**左侧导航**（搜索、分类、回收站 / 设置 / 帮助 / 关于）、**中间历史列表**、**右侧详情面板**。

- **自动记录**：你复制的任何内容（`⌘C` / `Ctrl+C`）都会自动出现在历史列表中，无需手动保存。
- **重新使用**：在列表选中某条，点击右侧「复制」或按 `Enter`，内容会写回系统剪贴板，随后直接粘贴即可。
  - 文本 / 链接 / 代码 → 写回文字；
  - **图片** → 以 PNG 写回，可在任意支持处粘贴为图片；
  - **文件** → 以真实文件 URL 写回，可在访达 / 文件管理器中粘贴为文件本身（库内仅保存文件路径，不入库存放文件内容）。
- **另存为（图片 / 文件）**：在历史列表的条目上通过**悬浮菜单**选择「另存为」，可将图片或文件保存到本机指定位置；对于局域网共享收到的图片与文件同样适用，便于把共享内容落地到本地。
  - 图片 → 以 PNG 保存到所选路径；
  - 文件 → 按原始文件名保存到所选路径（目录包 / 文件夹保留层级结构）。
- **置顶**：点击「置顶」（快捷键 `P`）把常用条目钉在列表顶部，不被新内容冲掉。
- **收藏**：点击「收藏」（快捷键 `F`）把条目加入收藏，方便长期保留。
- **删除**：点击「删除」（快捷键 `Delete` / `Backspace`）把条目移入回收站，可在回收站恢复。
- **用默认浏览器打开（链接）**：将鼠标移到链接条目上，点击悬浮菜单中的「用默认浏览器打开」，即可在系统默认浏览器中打开该网址。
- **清除全部**：主列表工具栏的「清除全部」按钮，二次确认后将所有历史软删入回收站（可恢复）。

> 提示：列表中的「来源应用」「大小」「时间」等元信息帮助你快速分辨内容出处；列表与详情区域的按钮均带有**悬浮提示**（鼠标悬停即显示功能说明），代码类内容在详情面板中以**语法高亮**呈现，列表内容变化时自动选中首行以便立即操作。

## 三、分类筛选与搜索

左侧导航按内容类型分了 **全部 / 文本 / 链接 / 代码 / 图片 / 文件** 六类，点击即可只看对应类型（`⌘1`–`⌘6`）。列表上方的「时间」筛选支持 **今天 / 昨天 / 本周 / 本月 / 全部**，还可「指定日期」精确到某一天；「来源」筛选可按复制内容的来源应用（如浏览器、终端）过滤。顶部搜索框（快捷键 `⌘/`）可实时按关键词检索——匹配范围包括内容正文、来源应用与预览文本，输入框右侧的「清除」按钮可一键清空关键词。

顶部搜索框（快捷键 `⌘/`）可实时按关键词检索——匹配范围包括内容正文、来源应用与预览文本，快速定位历史里的某段内容。

## 五、设置

点击侧边栏「设置」（`⌘,`）打开设置页。设置分为**通用 / 安全 / 共享**三个标签，点击标签切换：

### 5.1 通用

- **外观**：主题支持浅色 / 深色 / 跟随系统（默认「跟随系统」，使用 Tauri 原生主题 API）；深色由根元素 `data-theme` 驱动设计 Token。
- **语言**：内置 简体中文 / 繁體中文 / English / 日本語 / Deutsch / Français，可手动指定或跟随系统。
- **存储**：
  - **历史上限（条）**：范围 50–50000，默认 1000；超出后最旧记录自动清理（下次启动生效）。
  - **托盘菜单历史条数**：范围 1–100，默认 30；保存即生效。
  - **留存过期**：设置保留天数，超期未置顶的历史与回收站内容会被自动清理（默认永久保留）。
  - **保存的历史类型**：分别开关文本 / 图片 / 文件的捕获，关闭的类型不再被记录（已存在记录保留）。
- **开机自启**：登录后自动启动 ClipStack（基于 `tauri-plugin-autostart`）。

### 5.2 安全

- **忽略的应用**：被加入列表的应用（如密码管理器、终端）其复制内容不会被 ClipStack 捕获，保护敏感信息。可手动输入，或从「已安装应用」列表中选择（macOS 显示 Finder 本地化中文名）。
- **主密码 / 应用锁**：设置主密码（≥6 位）后，手动锁定、窗口失焦或闲置超时需输入密码解锁；macOS 可开启 Touch ID / 登录密码解锁（需 Xcode Command Line Tools）。
  - 忘记主密码：重启程序 → 设置 → 安全 →「清除主密码」即可移除（无需旧密码），数据仍加密不受影响。
- **敏感内容掩码**：开启后，命中密码 / Token / 银行卡号的内容在预览中以 `••••••` 遮挡，原文仍加密且可正常复制。

### 5.3 共享（局域网同步）

- **局域网共享（LAN 同步）**：在同一局域网内端到端加密互享剪贴板，无服务器、不上云。配置项与开启步骤详见 [第九节](#九局域网共享lan-同步)。

## 八、安全与隐私

ClipStack 把「本地优先、隐私可控」放在首位，数据安全由以下几层保障：

- **本地加密（始终开启）**：剪贴板正文与图片 / 文件二进制以 **AES-256-GCM** 在本地 SQLite 中加密存储；加密密钥存于 `~/.clipstack/dbkey.dat`（权限 600），与主密码相互独立——修改或清除主密码都不会影响已加密的数据。
- **应用锁**：在「设置 → 安全」中可设置主密码；手动锁定、窗口失焦或闲置超时后需输入密码解锁。macOS 上可开启 **Touch ID / 登录密码**解锁（需安装 Xcode Command Line Tools）。主密码仅用于解锁应用，不参与数据加解密。
- **敏感内容掩码**：开启「掩码敏感内容」后，命中密码 / Token / 银行卡号等规则的内容在列表与详情中以 `••••••` 遮挡预览；原文仍加密存储且可正常复制，开关即时生效。
- **留存过期**：在「设置 → 通用 → 留存过期」中设置保留天数，超过后未置顶的历史与回收站内容会被自动清理，避免敏感数据无限累积。
- **保存类型过滤**：在「设置 → 通用 → 保存的历史类型」中可分别开关文本 / 图片 / 文件的捕获，关闭的类型不再被记录（已存在记录保留）。

> 提示：锁定态下 ClipStack 仍会持续加密捕获剪贴板，复制内容不会因锁定而丢失；解锁只需密码或 Touch ID，安全与使用体验兼顾。

## 九、局域网共享（LAN 同步）

ClipStack 内置**局域网共享**：同一局域网（WiFi / 有线）内的多台设备可端到端加密互享剪贴板，无需服务器、不上云。

### 9.1 工作原理

**整体架构：无服务器 P2P 全 mesh 直连。**

- **零部署**：同一子网内无需填 IP、无需服务器，开箱即用。
- **全 mesh 拓扑**：每台设备**既是监听方也是发起方**，N 台设备两两互联（每台连 N-1 台）；**任意一台退出 / 掉线不影响其余设备**继续互享，没有中心节点、没有单点故障。
- **自动发现（mDNS）**：设备通过局域网多播 DNS 自动发现彼此（纯 Rust 实现，不依赖系统 Bonjour / Avahi，终端用户零额外安装）：
  - 启动时注册服务实例（如 `我的电脑._clipstack._tcp.local`），携带本机 IP、端口、设备名与**指纹**；
  - 持续广播查询，新设备上线即主动通告，其余设备无需轮询立即可感知；下线通过 goodbye 包或心跳超时自动移除。
- **分组与鉴权（指纹匹配）**：共享是否建立由 **共享组 与 密钥** 两项共同决定，二者**必须同时完全一致**才建立共享：

  ```
  指纹 = SHA256(共享组 :: 密钥) 的前 8 字节
  ```

  - 共享组不同 → 指纹不同 → 不连接；密钥不同 → 指纹不同 → 不连接；两者都一致 → 指纹必一致 → 才连接。
  - 指纹**不含密钥原文**，局域网广播不泄露密钥。
- **连接收敛**：任意两机之间按设备 ID 字典序决定**较大者向较小者发起连接**，恒为单条连接，避免双向重复连接；断线自动指数退避重连。
- **传输与去重**：每次复制是一条不可变事件，携带全局唯一 `sync_id`、来源设备、逻辑时钟与内容指纹：
  - 去重靠内容指纹 / `sync_id`，同一内容不会重复出现；
  - 排序靠 `(lamport 逻辑时钟, 设备 ID)`，多设备并发时全局顺序一致；
  - **回环防护**：收到对端的条目不再向第三方转发，避免广播在 mesh 中无限放大。
- **端到端加密（PSK）**：以共享组为盐、由共享密钥经 `PBKDF2-HMAC-SHA256(100000 轮)` 派生对称密钥，内容用 **AES-256-GCM 逐条加密**，每条随机 nonce 随信封传输——即使局域网被嗅探，也无法解密内容原文。
- **发布 / 接收分离（share_out）**：激活共享配置后，本机**始终接收**组内他人内容；「共享本机剪贴板」开关只控制**发布**（是否把本机复制内容发给他人）。关闭发布后仍照常接收他人内容，但**已发到对端的副本无法撤回**。
- **文件传输**：大文件与文件夹 / 目录包（如 macOS `.rtfd`）按 **32KB 分片**传输并在接收端重组，目录包保留层级结构，避免空闲超时误杀长传输。

### 9.2 开启前准备（三项必填）

在「设置 → 局域网共享」中先设置以下三项参数，**三者缺一不可**，未设置时开启共享会被拦截并提示：

- **共享组（Share Group）**：逻辑分组标识（如 `home` / `office`），只有同组的设备才会互享。
- **共享密钥（Share Key）**：对称密钥源，私密；与共享组一起决定能否建立共享。可显示 / 隐藏，留空表示保持现有密钥。
- **本机端口（Listen Port）**：本机监听端口，默认 **`21995`**。端口被占用时可改（如 `21996`），持久化保存，重启仍生效。

### 9.3 其余配置项

- **本机设备名（Device Name）**：显示在其他设备上的名称。
- **文件大小上限（File Limit）**：默认 **`10 MB`**，单文件超上限不共享；可在设置中调整。
- **共享类型（Share Types）**：白名单，默认文本 / 图片 / 文件三者皆共享，可分别开关。
- **手动对端地址（Manual Peers）**：跨网段 / 组播被禁时的兜底直连，格式 `地址:端口`（省略端口自动补 `21995`）。
- **在线设备（Online Devices）**：显示同组其它在线设备（显示设备名，不显示设备 ID）。
- **多配置文件（Profiles）**：可保存多组「组 + 密钥」并切换激活。

### 9.4 开启与使用

1. 进入「设置 → 共享 / 局域网共享」，填好共享组、共享密钥、端口三项。
2. 点击「共享本机剪贴板 / Share Out」开关；或在托盘菜单「共享」项点击切换（圆点亮 = 开、暗 = 关）。
3. 共享开启期间，共享组 / 密钥 / 设备名 / 端口 / 手动对端**不可修改**，需先关闭共享再改；文件大小上限与共享类型可随时改。
4. 收到的图片与文件可在历史列表的悬浮菜单选择「另存为」，保存到本机指定位置；也可打开「共享文件夹」（`~/.clipstack/share`）或一键清空其中的共享文件（移至系统回收站，可恢复）。

### 9.5 已知限制与注意事项

- **仅限同一局域网（本网段）**：mDNS 自动发现只在本网段生效；跨 VLAN / 跨网段**不支持自动发现**，需在「手动对端地址」中配置对方 `IP:端口` 直连（前提：两个网段之间已做路由且防火墙放行 `21995` 端口）。
- **防火墙提示**：首次运行系统可能弹出防火墙允许提示（UDP 5353 多播发现 / TCP 21995 监听端口），请选择允许，否则无法被发现或连接。
- **组播被禁的环境**：部分公司内网禁用组播，此时自动发现会失效，需改用「手动对端地址」。
- **不覆盖跨公网 / NAT 穿透**：本功能定位为同一局域网共享；跨公网 / NAT 穿透的中继同步（clipstack-relay）将在未来版本推出。
- **发布不可撤回**：关闭共享只停止发布**未来**的内容，已发送到对端的副本无法撤回（详见 9.1）。

> 局域网共享的技术设计文档位于项目仓库的 `docs/clipstack-lan-sync-design.md`。

## 常见问题（FAQ）

**Q：复制了内容却没出现在历史里？**
A：请确认已授予剪贴板访问权限，且来源应用不在「忽略的应用」列表中；部分安全软件也可能拦截。

**Q：关闭主窗口后还在运行吗？**
A：是的，ClipStack 默认驻留托盘后台运行以持续捕获剪贴板；从托盘菜单「退出」才会彻底关闭。

**Q：数据存在哪里？**
A：所有记录保存在本机本地数据库（SQLite），不上传任何云端。数据库中的剪贴板正文与图片 / 文件二进制以 AES-256-GCM 加密存储（密钥在 `~/.clipstack/dbkey.dat`，权限 600），即使数据库文件被拷贝走也无法直接读取明文。

**Q：局域网共享连不上？**
A：请确认双方共享组与共享密钥一致、端口未被占用且防火墙未拦截；跨 VLAN / 组播被禁时，在「手动对端」中填写对方 `IP:端口` 兜底直连。

**Q：忘记主密码怎么办？**
A：重启程序 → 设置 → 安全 →「清除主密码」即可移除（无需旧密码），已加密数据不受影响。

## 附录：开发环境要求

若需自行构建安装包（见 [1.3](#13-自己从源码构建进阶)），需准备：

| 依赖 | 说明 | 验证 |
|---|---|---|
| Node ≥ 22（nvm 管理）| 前端构建 / Vite | `node -v` |
| Rust 工具链（rustup + cargo）| 后端编译（Tauri 必需）| `cargo --version` |
| Xcode Command Line Tools（macOS）| 链接原生库、Touch ID 解锁 | `xcode-select -p` |

常用命令：

```bash
npm install            # 安装前端依赖
npm run tauri dev      # 启动完整 Tauri 应用（前端 + 原生窗口）
npm run tauri build    # 打包为安装包（mac: .dmg / .app；Win: .msi）
```
