# 敏感内容识别参考（Sensitive Content Detection Reference）

> 用途：为 ClipStack 剪贴板敏感内容识别（`src-tauri/src/clipboard.rs` 的 `is_sensitive`）
> 提供可落地的判定规则与厂商 Key 前缀清单。判定目标是「凭据 / 证件 / 卡号 / 强密码」，
> 命中即标记 `is_sensitive`，预览按「掩码敏感内容」开关遮挡（原文仍加密存储、可正常复制）。
>
> 数据采集日期：2026-08-14（来源：国家标准 GB 11643-1999 / GB 32100、NIST SP 800-63B 2024、
> ISO/IEC 7812、各厂商官方文档与社区汇总）。

---

## 一、中国大陆居民身份证

- **结构（18 位）**：6 位地址码 + 8 位出生日期（YYYYMMDD）+ 3 位顺序码 + 1 位校验码。
- **校验算法（GB 11643-1999，ISO 7064 MOD 11-2）**：
  1. 前 17 位权重 `W = [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2]`。
  2. `S = Σ(aᵢ × Wᵢ)`，`a₁₈ = (12 − (S mod 11)) mod 11`。
  3. 余数 → 校验码映射：`{0:'1', 1:'0', 2:'X', 3:'9', 4:'8', 5:'7', 6:'6', 7:'5', 8:'4', 9:'3', 10:'2'}`。
  4. 校验位为 `X`（罗马数字 10，大写）。
- **判定**：先正则 `^\d{17}[\dXx]$`，再算校验码核对；可叠加「出生日期 ≤ 今天、月份 1–12、日期 1–31」合理性检查降低误判。
- **注意**：15 位老身份证（无校验码）已停用，可忽略；`X` 大小写都接受但存储统一为大写。

## 二、手机号码（中国大陆）

- **基础**：`^1[3-9]\d{9}$`（11 位）。
- **更严格（覆盖 2024 全部公开号段）**：
  `^1(3[0-9]|4[5-9]|5[0-35-9]|6[2567]|7[0-8]|8[0-9]|9[0-35-9])\d{8}$`
- **判定前清洗**：用户常带空格 / 连字符 / 括号（如 `138-0013-8000`、`+86 138...`），先去除非数字字符再校验。
- **区分固定电话**：座机形如 `0\d{2,3}-\d{7,8}`，不应判为手机敏感（但也可视为一般敏感，按需）。

## 三、银行卡号（信用卡 / 储蓄卡）

- **结构（ISO/IEC 7812）**：13–19 位数字（多数 16 位），首数字标识卡组织：
  - `4` = Visa；`5`（51–55，或 2221–2720）= Mastercard；`3`（34/37）= Amex（15 位）；
    `3`（其余）= JCB / Diners；`6`（6011 / 644–649 / 65）= Discover；`62` = 银联（UnionPay）。
- **校验**：Luhn 算法（`mask_sensitive_read` 同思路）。
- **降低误判**：纯数字 + Luhn 会把部分长订单号 / 流水号误判。建议叠加「首数字 ∈ {2,3,4,5,6}」或已知 BIN 前缀命中，Amex 限 15 位、其余常见 16 位，长度作辅助。

## 五、强密码要求

- **NIST SP 800-63B（2024）**：最低 12–15 字符（推荐 ≥15），最长 ≥64；**不再强制**「大小写+数字+符号」组合；
  以**熵**衡量强度（长度比复杂度更重要）；应查泄露库、不强制定期更换。
- **熵公式**：`熵(bits) = 长度 × log₂(字符集大小)`。
  - 16 位全 ASCII(94) ≈ 105 bits；12 位混合 ≈ 52 bits；8 位全小写 ≈ 38 bits。
- **工程判定（启发式）改进方向**：
  - 阈值放严：熵从 `>3.0` 提到 `≥3.5–4.0`；「≥3 种字符类」作为**必要条件**而非「类数达标即可」。
  - **关键排除**：UUID（`8-4-4-4-12`）、纯十六进制串、base64、已知格式（邮箱 / URL / 代码）不应判为密码，否则误判率高。
  - 叠加弱密码表（`123456`、`password` 等）做排除 / 包含。
  - 长度门槛保持 ≥12 且**无空白**（整段为一行、无换行/空格）。

## 六、其它常见敏感类型（按需补）

- **邮箱**：`^[^\s@]+@[^\s@]+\.[^\s@]+$`
- **统一社会信用代码**：18 位（GB 32100），含 MOD 31 校验，可加。
- **护照号 / 港澳通行证 / 台湾通行证**：字母+数字，形态多、误判率高，建议保守处理。
- **IPv4 / IPv6 / MAC 地址**：可作为辅助敏感（内网拓扑泄露）。
- **私钥 PEM / `.env` 明文**：形态明确，命中即敏感。

## 七、对现有实现的结论

1. `is_sensitive` 当前只做 5 种 token 前缀 + Luhn 卡号 + 宽松密码启发式，**缺身份证、手机号、Stripe、大量国产/海外模型 key、私钥**。
2. `is_sensitive` 在**捕获时一次性落库**；改规则不会回溯修正历史条目。应改为**读取时实时重算**（参考现有 `mask_sensitive_read`），使历史条目即时生效。
3. 密码启发式过松（熵 `>3.0` + 仅需 ≥3 字符类），UUID / base64 / 长 hex 会被误判；需加排除规则并提高阈值。
